# 主题是运行时切换的 CSS，所有主题共用组件结构和 API

最终目标是一个可以在拟物、玻璃、像素等主题之间切换的完整组件库，所以所有主题共用同一份 DOM 结构和 API，主题只能改样式。主题能改的范围按从浅到深排是：token → CSS → 素材（字体、纹理、音效）→ JS 动效参数 → DOM 结构 → 交互行为。主题只覆盖前三层，另外可以附带可选的主题增强（比如玻璃折射需要的位移贴图脚本）。主题之间的结构差异，靠预留的装饰槽承载。主题可以不用某些槽（拟物主题目前不用 base 和 highlight，见 ADR 0006），但槽本身不随主题增减。

## Considered Options

- 单点样式集锦（每个组件按自己的风格单独做）：起步阻力最小，但每件作品的 API 和 DOM 各不相同，以后想统一切换主题只能全部重写。
- 允许主题改 DOM 或交互行为：每个主题等于一套独立的组件，维护量随主题数量成倍增加。
- 照搬 shadcn style 的做法：shadcn 在安装时把 `cn-*` 类名替换成具体的 Tailwind 类，装好后就不能再换。facet 要运行时切换，所以主题样式保留成独立的 CSS，不在安装时替换掉。
