# 项目名为 facet，协议 MIT

项目名是 facet，GitHub 仓库名和 registry 命名空间 `@facet` 都用它。这个名字是从 10 个候选里选出来的。facet 的意思是"切面"：同一颗宝石有不同的面，对应同一个组件的不同主题。它不偏向某一个主题，以后加了玻璃、像素也不会名不副实。名字不用作者本人的名字。2026-10-28 查过 shadcn registry 目录（ui.shadcn.com/r/registries.json，共 498 个命名空间），`@facet` 没被占用。改名要同时改仓库名、命名空间，以及每个使用方项目 components.json 里的配置，所以这里记一笔。

开源协议用 MIT。
